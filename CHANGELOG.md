# Changelog

## Changes since v1.3.0

### New Features
- **Simplified Architecture**: A new, streamlined architecture has been added to improve the overall structure and maintainability of the project.

- **MVVM and Signals State Managers**: The MVVM (Model-View-ViewModel) pattern along with a state management system using Signals have been integrated to enhance data handling and UI responsiveness.

- **Standalone Flavors Generator**: A standalone flavor generator has been added, providing flexibility for creating separate builds tailored to different environments or configurations.

### Improvements
- **Swagger Parser Fixes**: Various fixes have been implemented in the Swagger parser to improve its accuracy and stability.

### Enhancements
- **Base Data Components Preview**: A preview feature for base data components has been added, allowing developers to visualize and understand the data flow more effectively.

- **Added Backup for Standalone Signing Generator**: A backup mechanism has been included for the standalone signing generator to ensure that any configuration changes can be reverted if necessary.

### Bug Fixes
- Resolved an issue where adding screens to existing project functionality could lead to unexpected behavior.
